# 数据与素材来源说明

## 档案数据

本项目的 56 处黄河河南段遗址数据来自用户提供的原始「九曲云档」源码包：

```text
harmony-app/entry/src/main/resources/rawfile/heritages.json
```

该数据已同时导入云上 RDS 初始化脚本：

```text
scripts/seed.sql
```

## 图片素材

遗址图片来自原始源码包的 rawfile 目录：

```text
harmony-app/entry/src/main/resources/rawfile/images/
```

## 开源前必须确认

当前 README 与 LICENSE 只覆盖本项目新增代码的许可说明。**原始档案数据和图片是否允许公开，需要由团队向数据来源方确认。**

请在正式开源前完成：

1. 列出每条数据/图片的来源链接、作者、许可协议；
2. 对不允许公开的数据做脱敏或替换；
3. 在 `DATA_SOURCES.md` 中补充完整来源表；
4. 若数据来自公开文化机构，注明引用格式与访问日期；
5. 若图片为团队拍摄，补充拍摄者与授权说明。
